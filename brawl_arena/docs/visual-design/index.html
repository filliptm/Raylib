01 / North star

Built from the world

The interface should look like the station is presenting the match, not like a generic sci-fi website was placed over the game. Materials, type, and motion all reinforce the same fiction.

Hierarchy

One dominant decision

Every screen gets one obvious job. Character select chooses a brawler. Home launches a match. The HUD protects the combat view.

Material

Cut hull, not glass

Chamfered panels, inset rails, thin structural lines, and safety markings replace the current collection of interchangeable rounded cards.

Restraint

Effects earn meaning

Blue indicates interaction, gold indicates match-critical readiness, and role colors identify teams or abilities. Decorative glow stays rare.

02 / Color

Station palette

Dark values are cool and structural. Warm color belongs to action and industrial warning. Team state remains distinguishable by color, label, and shape—not hue alone.

Color usage rule

Safety orange is not the universal button color. Ion blue marks focus and editable state; gold is reserved for super readiness and the primary match launch; orange marks selection rails, warnings, and physical station hardware.

Runtime loading

Ship local font assets

Vendor the approved open-font files in resources/fonts/, load them once with LoadFontEx, apply bilinear filtering, and draw through DrawTextEx/MeasureTextEx. The HTML web import mirrors the locally shipped runtime families.

Scale

Named roles, not magic sizes

Define display, title, section, body, label, caption, and data roles. Scale them from the 1280×800 reference canvas and test at narrow and high-density window sizes before making the window resizable.

04 / Components

State is visible

Controls retain their shape when hovered or pressed. State changes through border, fill, rail, and focus treatment instead of moving the hit box.

LMB SHIFT Project saved Local draft Super ready
Input

Every control has focus

  • Mouse, keyboard, and controller share one focus model.
  • Primary targets are at least 44 logical pixels.
  • Focus is a bright outer edge, never color alone.
Feedback

Short and physical

  • Hover/focus settles in 160–180 ms.
  • Press uses a 2 px surface compression, not a layout jump.
  • Save feedback names the destination: local or project.
Motion

One rhythm

  • Screen transitions use a single 220–280 ms sequence.
  • Only ready/urgent state pulses, at a calm shared cadence.
  • Reduced motion removes orbit, pulse, and screen sweeps.

05 / Engineering bridge

Build the system first

Repainting the existing calls one by one would preserve the inconsistency. Establish shared presentation primitives, then move screens onto them.
